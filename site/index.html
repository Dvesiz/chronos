常见问题

需要安装才能体验吗？

打开在线体验即可使用计划、计时和统计。桌面小组件、精确提醒和极度沉浸需要 Android 版。

换手机或清理浏览器前，如何保留数据？

在设置里选择「导出学习数据」，在新设备上导入 JSON 文件。也可以登录同一账号使用多设备同步。

Android 下载后如何安装？

在 Android 8.0 或更高版本上打开下载的 APK。如果系统询问是否允许从当前来源安装，按提示为下载工具开启权限。其他版本和更新记录可在 GitHub Releases 查看。
